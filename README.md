# Тренажёр диалогов для аптек — макет

Кликабельный макет мобильного веб-тренажёра по ТЗ (`TZ_trenazher_dlya_razrabotchika.docx`).
Без базы данных: контент лежит в JSON-файлах, прогресс и журнал событий хранятся в `localStorage` браузера.

## Запуск

```
node server.js
```

Откройте http://localhost:3456 (другой порт: `PORT=4000 node server.js`).
Нужен только Node.js, без зависимостей. Через `file://` не работает: контент загружается через `fetch`.

Вход: любой логин и пароль (по умолчанию `demo` / `demo`).
Вход «из портала» имитируется параметрами URL: `/?uid=123&fio=Иванова%20Анна&network=Аптека%20Плюс&region=Москва&position=Провизор`.

## Устройство

```
server.js            — статический сервер
js/engine.js         — движок диалогов (не знает о препаратах)
js/app.js            — экраны и роутер
js/validator.js      — автопроверка структуры контента
js/events.js         — журнал событий
js/reports.js        — отчёты из журнала + Excel
js/demo.js           — генератор демо-журнала (42 вымышленных сотрудника)
content/             — контент; формат описан в content/schema.md
```

Новый диалог: положите JSON в `content/memoritab/dialogs/` и добавьте его id в `product.json` → `dialogs`.
Новый препарат: папка `content/<id>/` с теми же файлами и id в `content/index.json`.

## Ограничения макета

- Озвучка — синтез речи браузера; в шаблоне есть поле `audio` для настоящих mp3.
- Видео — открытый тестовый ролик вместо ролика заказчика.
- Excel (SheetJS) и сохранение памятки картинкой (html2canvas) загружаются с cdnjs; без интернета отчёт выгружается в CSV.
- Данные видны только в этом браузере. Сервер, БД, интеграция с порталом и хранение в РФ — следующий этап.
