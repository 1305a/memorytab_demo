# Шаблон контента тренажёра

Движок не знает о конкретном препарате. Весь контент — JSON-файлы в папке `content/`.
Новый диалог, аватар или препарат добавляется без изменения кода.

```
content/
  index.json                 — список препаратов: { "products": ["memoritab", ...] }
  <productId>/
    product.json             — препарат: теория, памятка, видео, компетенции, список диалогов
    avatars.json             — аватары (покупатели)
    dialogs/<dialogId>.json  — диалоги
    audio/<dialogId>/*.mp3   — озвучка реплик (необязательно)
```

## product.json

| Поле | Описание |
|---|---|
| `id`, `title`, `subtitle` | Идентификатор и название препарата |
| `competencies[]` | `{ id, name, description }` — набор компетенций для отчётов |
| `theory[]` | Карточки теории: `{ icon, title, text, bullets? }` |
| `memo` | Памятка: `{ title, sections: [{ icon, title, tone?: "warn"\|"tip", items: [] }] }` |
| `video` | `{ title, src, poster?, duration, description, chapters?: [{ time, title }] }` |
| `dialogs[]` | Порядок диалогов — имена файлов из `dialogs/` без `.json` |

## avatars.json

```json
{
  "id": "a01", "name": "Артём", "age": 20, "short": "студент перед сессией",
  "legend": "Кто это", "situation": "С чем пришёл",
  "image": "img/a01.png",
  "look": { "skin": "#f3cfb0", "hair": "#3a2a1f", "hairStyle": "curly", "shirt": "#ff8a3d", "glasses": false, "beard": false, "wrinkles": false },
  "voice": { "gender": "m", "pitch": 1.1, "rate": 1.1, "index": 0 }
}
```

`image` — путь к картинке относительно папки препарата. Если его нет, аватар рисуется по `look`
(`hairStyle`: short, long, bun, curly, bald). `voice` — параметры синтеза речи для макета:
голос у персонажа один на все реплики.

## Диалог

```json
{
  "id": "d01",
  "version": 1,
  "productId": "memoritab",
  "avatarId": "a01",
  "title": "Сессия через неделю",
  "start": "s1",
  "steps": {
    "s1": {
      "text": "Реплика покупателя",
      "audio": "audio/d01/s1.mp3",
      "options": [
        {
          "id": "a",
          "text": "Вариант ответа фармацевта",
          "score": 10,
          "correct": true,
          "competency": "needs",
          "feedback": "Разбор: почему так хорошо или плохо",
          "next": "s2"
        }
      ]
    }
  },
  "finals": {
    "f_sale": { "outcome": "sale", "title": "Покупка совершена", "text": "Итог диалога" }
  }
}
```

- В шаге 2–4 варианта; в тренажёре они показываются в случайном порядке.
- `next` — id следующего шага или финала. Так задаётся ветвление (соглашается / сомневается / уходит).
- `outcome` финала: `sale` (продажа), `safe` (безопасная консультация без продажи), `doubt`, `leave`, `risk` (опасная рекомендация).
- Максимум баллов за шаг — наибольший `score` среди вариантов.
- `audio` необязателен; без него в макете реплика озвучивается синтезом речи браузера.

## Версии

Если опубликованный диалог меняется, увеличьте `version`. Каждое событие в журнале хранит версию диалога,
поэтому старая статистика не ломается. Незаконченные прохождения старой версии начинаются заново.

## Автопроверка

Экран «Проверка контента» (`#/check`) проверяет: пустые поля, 2–4 варианта, битые переходы,
неизвестные компетенции и аватары, недостижимые шаги, тупики (шаги, из которых нельзя дойти до финала).
Там же можно загрузить новый JSON и пройти его на тестовом стенде до выкладки.
